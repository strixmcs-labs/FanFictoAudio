# Version 1.5.1 — OpenRouter narration and faster AI speeds

## Changes

**OpenRouter** joins macOS voices, OpenAI, and ElevenLabs as a speech provider, using your own OpenRouter API key saved in Keychain. **Load Models** lists OpenRouter's speech models and the voices each one offers. The list comes from OpenRouter's public catalog, so no key or book text is sent. Choosing a model fills in its listed per-character rate when you haven't entered one. The default is Kokoro 82M with the `af_heart` voice. Speech is requested as MP3. Gemini TTS and HeyGen Voice return only raw PCM and are left out of the list.

AI narration now goes up to **6×** with every provider. Each provider is asked for the closest speed it supports (OpenAI up to 4×, ElevenLabs 0.7–1.2×, OpenRouter always 1×). The rest of the change is applied to the returned audio without changing pitch, so speed works with every OpenRouter model. Previews play at the chosen speed. The bundled encoder now includes FFmpeg's `atempo` filter for this.

## Requirements

Apple silicon and macOS 14 or later. Python, [FanFicFare](https://github.com/JimmXinu/FanFicFare), and a standalone FFmpeg/LAME encoder are bundled. FanFicFare, by Jim Miller (JimmXinu) and its contributors, powers story downloading, metadata, site adapters, and EPUB writing/updating. Provider keys stay in macOS Keychain.
